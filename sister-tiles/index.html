✦ Sister Tiles ✦

Play together from wherever you are — one sister hosts, everyone else joins with the room code.

Start a game (Host)

The host is Player 1 and the referee: her browser holds the tile bag and keeps score.

Important: the host must keep her tab open for the whole game. If she closes it, the game ends for everyone.

Join a game

Ask the host for her 5-letter room code, type it in, and join.

Quick rules

Build lines of tiles that are all the same color with different shapes, or all the same shape with different colors. No duplicates in a line, and a line can have at most 6 tiles. All tiles you play in one turn must be in a single row or column and touch the board. You score the length of every line you create or extend, and completing a line of 6 is a Full Six, +6 bonus!
